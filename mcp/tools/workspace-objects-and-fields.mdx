## Get the workspace

`heliyos_organization_get` · **Read** · Idempotent

Returns the Heliyos workspace this API key belongs to: its id and name, billing status, active plan, member count, how many companies, people and deals it holds, and how many companies are watched out of the plan's limit. Call it first to orient yourself. Use heliyos_objects_list for the objects and their schema ids, heliyos_usage_get for credit usage. Returns structuredContent \{organization\}.

This tool takes no inputs.

### Returns

A readable text summary, plus `structuredContent` with `organization`.

### API endpoints

- [Get the workspace](/api-reference/workspace/get-the-workspace) · `GET /v1/platform/organization`

## List objects

`heliyos_objects_list` · **Read** · Idempotent

Lists the workspace's objects (record types): companies, people, deals and any custom objects, with each one's schema_id, object_type, record count and number of fields. Use it to learn which object_type and schema_id to pass to the heliyos_records_* tools (custom objects need schema_id), then heliyos_objects_get for an object's field keys. Returns every object in one page (a workspace has a handful), as structuredContent \{objects\}.

### Inputs

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns one line per object; "detailed" returns each object's field keys too. One of `concise`, `detailed`.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `objects`.

### API endpoints

- [List objects](/api-reference/schemas/list-objects) · `GET /v1/platform/base-schemas`

## Get an object's fields

`heliyos_objects_get` · **Read** · Idempotent

Returns one object's fields: each field key (what heliyos_records_create, _update and _list filters take), its label and type, and which are required. "detailed" adds the allowed values of select fields, hidden and AI-filled flags, and the target object of relationship fields. Pick the object with object_type (company, person, deal, or custom with schema_id from heliyos_objects_list). Each field's field_id feeds heliyos_fields_update and heliyos_fields_delete; heliyos_fields_create adds one. Returns structuredContent \{object:\{schema_id, name, fields:[\{key, field_id, type, ...\}]\}\}.

### Inputs

<ParamField path="object_type" type="string" required>
  Which object: "company", "person", "deal", or "custom" (custom objects also need schema_id). One of `company`, `person`, `deal`, `custom`.
</ParamField>

<ParamField path="schema_id" type="string">
  Object schema id. Required when object_type is "custom"; the error lists the available ones. A 24-character hex id.
</ParamField>

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns each field's key, label and type; "detailed" returns select options and field flags too. One of `concise`, `detailed`.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `object`.

### API endpoints

- [Get an object](/api-reference/schemas/get-an-object) · `GET /v1/platform/base-schemas/{id}`

## Add a field to an object

`heliyos_fields_create` · **Write**

Adds one field (column) to an object: companies, people, deals or a custom object (object_type, plus schema_id for custom). Give it a label and a type; select and multiSelect need `options`; `ai_prompt` makes it an AI column. The field key (what record `fields` and filters use) is derived from the label unless `key` is given, and must be new on the object. Relationship fields are created in the Heliyos web app. Calling this twice with the same key fails. Returns structuredContent \{field:\{field_id, key, label, type\}\}.

### Inputs

<ParamField path="object_type" type="string" required>
  Which object: "company", "person", "deal", or "custom" (custom objects also need schema_id). One of `company`, `person`, `deal`, `custom`.
</ParamField>

<ParamField path="schema_id" type="string">
  Object schema id. Required when object_type is "custom"; the error lists the available ones. A 24-character hex id.
</ParamField>

<ParamField path="label" type="string" required>
  Display name, for example "Contract value". Up to 100 characters.
</ParamField>

<ParamField path="key" type="string">
  Field key, for example contract_value. Derived from the label when omitted.
</ParamField>

<ParamField path="type" type="string" required>
  One of text, richText, number, currency, rating, checkbox, date, timestamp, select, multiSelect, url, email, phone, user, image, file. One of `text`, `richText`, `number`, `currency`, `rating`, `checkbox`, `date`, `timestamp`, `select`, `multiSelect`, `url`, `email`, `phone`, `user`, `image`, `file`.
</ParamField>

<ParamField path="description" type="string">
  What the field holds; shown in the web app and read by the workers. Up to 1000 characters.
</ParamField>

<ParamField path="options" type="string[]">
  Allowed values of a select or multiSelect field, unique. Up to 200 items.
</ParamField>

<ParamField path="required" type="boolean">
  Records must have a value. Default false.
</ParamField>

<ParamField path="hidden" type="boolean">
  Hidden from the web app's tables by default. Default false.
</ParamField>

<ParamField path="visibility" type="string" default="organization">
  "organization" (default): every member sees it; "private": only owners and admins. One of `organization`, `private`.
</ParamField>

<ParamField path="ai_prompt" type="string">
  Makes this an AI column: the workers fill it from this prompt (text, richText, number, date, select, multiSelect or checkbox only). Filling existing records is started from the Heliyos web app and uses credits. Up to 5000 characters.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `field`.

## Change a field

`heliyos_fields_update` · **Destructive** · Idempotent

Changes one field of an object by field_id (from heliyos_objects_get): its label, description, options, required or hidden flag, AI prompt, or type. What you leave out is kept. `options` REPLACES the allowed values, and records holding a removed value keep it as stale text. A type change is refused by the platform when existing values do not fit the new type. The field key never changes. Returns structuredContent \{field\}.

## Delete a field

`heliyos_fields_delete` · **Destructive** · Idempotent

Permanently deletes one field of an object by field_id (from heliyos_objects_get) AND its value on every record. This cannot be undone: confirm with the user first, naming the field and the object. Built-in required fields (for example a company's name) are refused by the platform. Returns structuredContent \{field_id, key, deleted\}.

### Inputs

<ParamField path="object_type" type="string" required>

</ParamField>

<ParamField path="schema_id" type="string">

</ParamField>

<ParamField path="field_id" type="string" required>
  field_id: a 24-character hex id. A 24-character hex id.
