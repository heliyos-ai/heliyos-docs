## Get notification settings

`heliyos_notification_settings_get` · **Read** · Idempotent

Returns the workspace's notification email settings: whether they are on, who receives them, and which events notify (each immediate or in a daily digest). Returns structuredContent \{settings:\{configured, is_active, notify_emails, event_types:[\{type, frequency\}]\}\}.

This tool takes no inputs.

### Returns

A readable text summary, plus `structuredContent` with `settings`.

### API endpoints

- [Get notification settings](/api-reference/notification-settings/get-notification-settings) · `GET /v1/platform/notification-settings`

## Update notification settings

`heliyos_notification_settings_update` · **Write** · Idempotent

Changes the workspace's notification email settings. Each key you pass REPLACES that setting: notify_emails is the full recipient list and event_types the full list of notifying events (read the current ones with heliyos_notification_settings_get and send the complete list). Keys you leave out are kept. scout.signal_detected is always immediate. Returns structuredContent \{settings\}.

### Inputs

<ParamField path="is_active" type="boolean">
  Turns all notification emails on or off.
</ParamField>

<ParamField path="notify_emails" type="string[]">
  Every recipient address (replaces the list). Up to 50 items.
</ParamField>

<ParamField path="event_types" type="object[]">
  Every event that should notify, each immediate or daily (replaces the list). Up to 10 items.
  <Expandable title="item properties">
    <ParamField path="type" type="string" required>
      The event, for example task.created or deal.approval. One of `task.created`, `task.updated`, `deal.created`, `deal.updated`, `deal.approval`, `leadset.created`, `leadset.records.available`, `organization.daily_summary`, `scout.signal_detected`, `integration.not_synced`.
    </ParamField>
    <ParamField path="frequency" type="string" required>
      "immediate" (one email per event) or "daily" (in the daily digest). One of `immediate`, `daily`.
    </ParamField>
  </Expandable>
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `settings`.

### API endpoints

- [Update notification settings](/api-reference/notification-settings/update-notification-settings) · `PATCH /v1/platform/notification-settings`
