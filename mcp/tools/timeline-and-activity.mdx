## Read a record's timeline

`heliyos_records_timeline` · **Read** · Idempotent

Returns the AI-written timeline of one record (company, person or deal): the record's current relationship summary and dated entries describing what happened (emails, meetings, deal moves), newest first. Use it to brief yourself on an account before acting. For the raw audit trail of field changes use heliyos_records_events; for the emails and meetings themselves use heliyos_interactions_list. Returns structuredContent \{record_id, summary, entries, next_cursor\}.

### Inputs

<ParamField path="record_id" type="string" required>
  record_id: a 24-character hex id. A 24-character hex id.
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Entries per page, 1 to 100. Default 20. From 1 to 100.
</ParamField>

<ParamField path="cursor" type="string">
  next_cursor from the previous page, with the same limit. Omit for the first page. Up to 200 characters.
</ParamField>

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns each entry cut at 300 characters; "detailed" returns full entry text. One of `concise`, `detailed`.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `record_id`, `summary`, `entries`, `total`, `next_cursor`.

### API endpoints

- [List timeline entries](/api-reference/timeline/list-timeline-entries) · `GET /v1/platform/records/{id}/timeline`

## Read a record's change history

`heliyos_records_events` · **Read** · Idempotent

Returns the audit trail of one record: who changed what and when (people and workers), newest first, each with a one-line change summary. Filter by operation type, event type, date range or text. "detailed" adds the paths of the changed fields. Use heliyos_records_timeline instead for a narrative of the relationship. Returns structuredContent \{events:[\{id, at, operation_type, actor, change_summary\}], next_cursor\}.

### Inputs

<ParamField path="record_id" type="string" required>
  record_id: a 24-character hex id. A 24-character hex id.
</ParamField>

<ParamField path="operation_types" type="string[]">
  Only these operations: CREATE, UPDATE, DELETE. Up to 3 items.
</ParamField>

<ParamField path="event_types" type="string[]">
  Only these event types: AUDIT (field changes), INTERACTION (emails, meetings), ENRICHMENT. Up to 3 items.
</ParamField>

<ParamField path="since" type="string">
  since as an ISO 8601 date (2026-03-01) or date-time (2026-03-01T09:00:00Z). Up to 40 characters.
</ParamField>

<ParamField path="until" type="string">
  Only events at or before this date; a date alone includes that whole day (UTC). Up to 40 characters.
</ParamField>

<ParamField path="search" type="string">
  Plain words matched against the change summaries. Symbols such as + ( ) [ ] * ? can cause an error. Up to 200 characters.
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Events per page, 1 to 100. Default 20. From 1 to 100.
</ParamField>

<ParamField path="cursor" type="string">
  next_cursor from the previous page, with the same limit. Omit for the first page. Up to 200 characters.
</ParamField>

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns one line per change; "detailed" returns the changed field paths too. One of `concise`, `detailed`.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `events`, `next_cursor`.

### API endpoints

- [List record events](/api-reference/activities/list-record-events) · `GET /v1/platform/records/{id}/events`

## List emails and meetings

`heliyos_interactions_list` · **Read** · Idempotent

Lists synced emails and meetings, newest first, optionally only those linked to one record (record_id) or of one channel. Each has its subject or title, time, AI summary and the records it is linked to. "detailed" adds participants and next steps; heliyos_interactions_get returns one with its full summary. Order with `sort`. Returns structuredContent \{interactions:[\{id, channel, title, at, summary, record_ids\}], next_cursor\}.

### Inputs

<ParamField path="record_id" type="string">
  Only interactions linked to this record (company, person or deal). A 24-character hex id.
</ParamField>

<ParamField path="channel" type="string">
  Only emails or only meetings. One of `email`, `meeting`.
</ParamField>

<ParamField path="search" type="string">
  Plain words matched against subjects, titles and summaries. Symbols such as + ( ) [ ] * ? can cause an error. Up to 200 characters.
</ParamField>

<ParamField path="sort" type="object">
  Sort order. Omit for newest first. With a sort, next_cursor is a page cursor from this tool; pass it back unchanged.
  <Expandable title="properties">
    <ParamField path="field" type="string" required>
      last_message (newest email thread message), start_time (meeting start) or created_at (when it was synced). One of `last_message`, `start_time`, `created_at`.
    </ParamField>
    <ParamField path="direction" type="string" default="desc">
      "asc" or "desc" (default). One of `asc`, `desc`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Interactions per page, 1 to 100. Default 20. From 1 to 100.
</ParamField>

<ParamField path="cursor" type="string">
  next_cursor from the previous page, with the same limit. Omit for the first page. Up to 200 characters.
</ParamField>

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns subject, time and a summary cut at 300 characters; "detailed" returns the full summary, participants and next steps. One of `concise`, `detailed`.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `interactions`, `next_cursor`.

### API endpoints

- [List interactions](/api-reference/interactions/list-interactions) · `GET /v1/platform/interactions`

## Get an email or meeting

`heliyos_interactions_get` · **Read** · Idempotent

Fetches one synced email thread or meeting by id (from heliyos_interactions_list or heliyos_records_timeline): subject or title, time, the AI summary, sentiment, the records it is linked to, participants and next steps. "concise" cuts the summary; "detailed" returns all of it. Returns structuredContent \{interaction\}.

### Inputs

<ParamField path="interaction_id" type="string" required>
  interaction_id: a 24-character hex id. A 24-character hex id.
</ParamField>

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns the summary cut at 300 characters; "detailed" returns the full summary, participants and next steps. One of `concise`, `detailed`.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `interaction`.

### API endpoints

- [Get an interaction](/api-reference/interactions/get-an-interaction) · `GET /v1/platform/interactions/{id}`
