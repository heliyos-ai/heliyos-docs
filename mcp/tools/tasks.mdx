## List tasks

`heliyos_tasks_list` · **Read** · Idempotent

Lists tasks, newest first, optionally only those linked to one record (record_id), in one status, or matching text. Each task shows its id, title, status, priority, due date and whether workers are running on it. Use heliyos_tasks_get for the description and links. Returns structuredContent \{tasks:[\{id, title, status, ...\}], next_cursor\}.

### Inputs

<ParamField path="record_id" type="string">
  Only tasks linked to this record. A 24-character hex id.
</ParamField>

<ParamField path="status" type="string">
  backlog, in_progress, scheduled_for_later (a worker set a wake-up for it), on_hold (waiting on a person or an event), cancelled or completed. One of `backlog`, `in_progress`, `scheduled_for_later`, `on_hold`, `cancelled`, `completed`.
</ParamField>

<ParamField path="search" type="string">
  Plain words matched against task titles and descriptions. Symbols such as + ( ) [ ] * ? can cause an error. Up to 200 characters.
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Tasks per page, 1 to 100. Default 20. From 1 to 100.
</ParamField>

<ParamField path="cursor" type="string">
  next_cursor from the previous page, with the same limit. Omit for the first page. Up to 200 characters.
</ParamField>

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns one row per task; "detailed" returns assignees, workers and linked records too. One of `concise`, `detailed`.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `tasks`, `next_cursor`.

### API endpoints

- [List tasks](/api-reference/tasks/list-tasks) · `GET /v1/platform/tasks`

## Read a task's activity

`heliyos_tasks_events` · **Read** · Idempotent

Returns the activity (change history) of one task: who changed what and when (people and workers), newest first, each with a one-line change summary. "detailed" adds the paths of the changed fields. For a company, person or deal use heliyos_records_events; for what the workers did on the task use heliyos_runs_list with task_id. Returns structuredContent \{events:[\{id, at, operation_type, actor, change_summary\}], next_cursor\}.

</ParamField>

<ParamField path="cursor" type="string">

</ParamField>

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns one line per change; "detailed" returns the changed field paths too. One of `concise`, `detailed`.

## Create a task

`heliyos_tasks_create` · **Write**

Creates a task, optionally linked to records (a company, person or deal). Creating a task can start workers that subscribe to new tasks. Calling it twice creates two tasks. To have workers act on it now, call heliyos_tasks_run with the returned id. Returns structuredContent \{task\}.

### Inputs

<ParamField path="title" type="string" required>
  Task title. Up to 500 characters.
</ParamField>

<ParamField path="description" type="string">
  Task description (plain text). Up to 20000 characters.
</ParamField>

<ParamField path="status" type="string">
  Default backlog. One of `backlog`, `in_progress`, `scheduled_for_later`, `on_hold`, `cancelled`, `completed`.
</ParamField>

<ParamField path="priority" type="string">
  none, low, medium, high or urgent. One of `none`, `low`, `medium`, `high`, `urgent`.
</ParamField>

<ParamField path="due_date" type="string">
  due_date as an ISO 8601 date (2026-03-01) or date-time (2026-03-01T09:00:00Z). Up to 40 characters.
</ParamField>

<ParamField path="record_ids" type="string[]">
  Ids of records (companies, people, deals) to link the task to, 1 to 10. Each id is checked first; an unknown id fails the call and nothing is written. Up to 10 items.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `task`.

### API endpoints

- [Create a task](/api-reference/tasks/create-a-task) · `POST /v1/platform/tasks`

## Run workers on a task

`heliyos_tasks_run` · **Destructive**

Starts the workers (AI agents) on one task now and marks it in progress. If a run is already open, returns that run instead of starting another. Runs use credits; the call fails when the workspace is out of them. Returns structuredContent \{task_id, run_id, started, status\}; follow the run with heliyos_runs_get using run_id.

### Inputs

<ParamField path="task_id" type="string" required>
  task_id: a 24-character hex id. A 24-character hex id.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `task_id`, `run_id`, `started`, `status`.

### API endpoints

- [Run workers on a task](/api-reference/tasks/run-workers-on-a-task) · `POST /v1/platform/tasks/{id}/runs`
