## List notes

`heliyos_notes_list` · **Read** · Idempotent

Lists notes, newest first, optionally only those linked to one record (record_id) or matching text in the title or body. Each note shows its id, title, a short preview and the records it is linked to. Use heliyos_notes_get for the full text. Returns structuredContent \{notes:[\{id, title, content, links\}], next_cursor\}.

### Inputs

<ParamField path="record_id" type="string">
  Only notes linked to this record. A 24-character hex id.
</ParamField>

<ParamField path="search" type="string">
  Plain words matched against note titles and bodies. Symbols such as + ( ) [ ] * ? can cause an error. Up to 200 characters.
</ParamField>

<ParamField path="limit" type="integer" default="20">
  Notes per page, 1 to 100. Default 20. From 1 to 100.
</ParamField>

<ParamField path="cursor" type="string">
  next_cursor from the previous page, with the same limit. Omit for the first page. Up to 200 characters.
</ParamField>

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns a 200-character preview; "detailed" returns each note's full text and times. One of `concise`, `detailed`.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `notes`, `next_cursor`.

### API endpoints

- [List notes](/api-reference/notes/list-notes) · `GET /v1/platform/notes`

## Get a note

`heliyos_notes_get` · **Read** · Idempotent

Fetches one note by id with its title, text and linked records. "concise" cuts the text at 1500 characters; "detailed" returns all of it plus created and updated times. Returns structuredContent \{note\}.

### Inputs

<ParamField path="note_id" type="string" required>
  note_id: a 24-character hex id. A 24-character hex id.
</ParamField>

<ParamField path="response_format" type="string" default="concise">
  "concise" (default) returns the text cut at 1500 characters; "detailed" returns the full text and times. One of `concise`, `detailed`.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `note`.

### API endpoints

- [Get a note](/api-reference/notes/get-a-note) · `GET /v1/platform/notes/{id}`

## Create a note

`heliyos_notes_create` · **Write**

Creates a note, optionally linked to records (a company, person or deal) so it shows on them and can trigger workers. Calling it twice creates two notes. Returns the new note's id as structuredContent \{note\}.

### Inputs

<ParamField path="title" type="string" required>
  Note title. Up to 500 characters.
</ParamField>

<ParamField path="content" type="string">
  Note body (plain text or simple HTML). Up to 100000 characters.
</ParamField>

<ParamField path="record_ids" type="string[]">
  Ids of records (companies, people, deals) to link the note to, 1 to 10. Each id is checked first; an unknown id fails the call and nothing is written. Up to 10 items.
</ParamField>

### Returns

A readable text summary, plus `structuredContent` with `note`.

### API endpoints

- [Create a note](/api-reference/notes/create-a-note) · `POST /v1/platform/notes`

## Update a note

  Note body (plain text or simple HTML). Up to 100000 characters.

<ParamField path="record_ids" type="string[]">
