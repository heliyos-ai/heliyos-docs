---
title: "Troubleshooting"
description: "Fixes for the errors you are most likely to see."
---

| What you see | What to do |
| --- | --- |
| `heliyos-mcp: Set HELIYOS_API_KEY to a Heliyos API key` | The client did not pass the key. Check the `env` block, or that the variable is exported in the shell that started the client. |
| `HELIYOS_API_KEY does not look like a Heliyos API key` | The value is not a Heliyos key. Keys start with `heliyos_`. Copy it again or create a new one. |
| `UNAUTHENTICATED` | The key was revoked, has expired or was mistyped. Create a new key in **Settings → API keys**. |
| `FORBIDDEN_ACTION` | The workspace plan or billing status does not allow the action, or the action is not available to API keys. |
| `RATE_LIMITED` | You are above 60 requests per minute. Wait a minute, and prefer list calls over many single gets. |
| `heliyos_ask` times out | Raise the client's tool timeout (see [Configuration](/mcp/configuration#tool-timeout)). The run keeps going; follow it with `heliyos_runs_get`. |
| The server shows "connecting" on its first start | The first `npx -y @heliyos/heliyos-mcp` downloads the package, which can take 20 to 30 seconds and outlast a client's startup timeout. Warm the cache once from a terminal with `npx -y @heliyos/heliyos-mcp --version`, then reconnect; later starts take about a second. Or raise the timeout (Codex `startup_timeout_sec`, Claude Code `MCP_TIMEOUT=60000`). |
| `Node 16.x is too old`, or tools fail with `fetch is not defined` | The client started `npx` with an old Node, usually a version manager's default. The server needs Node 20 or newer and restarts itself on the newest suitable Node it finds (nvm, fnm, n, Volta, Homebrew, PATH); the message names which one. If it finds none, install Node 20+ or run `nvm install 20 && nvm alias default 20`, then restart the client. Apps opened from the dock may not find `npx` at all; use its full path from `which npx`. |

Still stuck? Open an issue at [github.com/heliyos-ai/heliyos-mcp/issues](https://github.com/heliyos-ai/heliyos-mcp/issues) or email [soham@heliyos.ai](mailto:soham@heliyos.ai). Never paste your key.
